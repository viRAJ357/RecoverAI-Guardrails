# RecoverAI

A payment-recovery command centre built for Razorpay. When a payment fails, RecoverAI evaluates the failure, applies safety guardrails, and recommends the best recovery action — with a full audit trail.

**Safe Demo Mode** is on by default — no API keys, no charges. Fully interactive dashboard.

See full documentation on [GitHub](https://github.com/viRAJ357/AI-Revenue-Recovery).
